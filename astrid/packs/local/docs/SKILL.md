# Local Elements Pack

Use this pack when a Remotion timeline needs one of the project-local visual
effect elements declared under `rendering/elements/effects`.

This pack supplies render-time element definitions, authored components, and
immutable assets. It does not execute generation, editing, or rendering; use the
owning generation or rendering capability for those operations.
