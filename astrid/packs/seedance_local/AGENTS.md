# Seedance Local

## Overview

Temporary personal adapter for Seedance 2.0 reference-to-video through fal.ai.

## Quick start

Inspect `seedance_local.reference_video`, install it once, then run it through
the canonical Astrid executor gateway.

## Safety

Every non-dry run is a paid external generation. Make one explicit attempt at
a time. Never persist the FAL key or fal.ai signed media URLs.
