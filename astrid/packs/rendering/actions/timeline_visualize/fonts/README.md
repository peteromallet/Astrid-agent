# Filmstrip fonts

`PowerGrotesk-Regular.ttf` is the designed face used for the filmstrip. The
PNG renderer bundles `NotoSansSC-Regular.ttf` and `NotoEmoji-Regular.ttf` as
module-relative fallbacks so missing CJK, Greek, and emoji glyphs remain
readable without depending on host fonts or a network request.

The Noto fonts are distributed under the SIL Open Font License 1.1. Their
upstream Google Fonts CSS sources are:

- https://fonts.googleapis.com/css2?family=Noto+Sans+SC:wght@400
- https://fonts.googleapis.com/css2?family=Noto+Emoji:wght@400
