# Merge goal and operative plan closure

## Goal

Integrate the useful code and authored data from the existing six-effort Astrid/Reigh/Runtime project into one coherent, reproducible system. Preserve implementation, tests, schemas, workflows, templates, documentation, resources, dependency/build definitions, provenance, and useful project content. An archive alone does not preserve a capability. Consolidate only when equivalent behavior and provenance remain proven. Keep all original source/main trees unchanged.

The final system combines Live Scenes, H3/T2 Worker retirement, Pack authoring convergence, Plan A final-state closeout, RunPod simplification, and preferences/documents/hosted/OMP. It retains Runtime task/project/publication authority, host process custody, editor/rendering and saved-chat behavior, authenticated app connectivity, reproducible installed closure, and equivalent worker-free recovery/supervision. Preserve platform distinctions: macOS CPU, Linux/native, and provider/operational qualification claims remain separate.
