## Findings (verified, file:line)

**1. `projects list` semantics** — positional `project_id` (reigh UUID), `--json` (project.py:187-193). `_cmd_list` (project_handlers.py:340-377) POSTs `{project_id}` to the reigh-data-fetch Edge Function with PAT (346-351), projecting `timelines[]` id/name/config_version/updated_at (352-366). Read-only, fully remote; never touches the local project store.

**2. `projects edit` semantics** — `--timeline-id` (required), `--service-role`, `--json`; sub-verbs `add-clip|move-clip|set-theme` only (project.py:195-221). `_cmd_edit` (project_handlers.py:380-439): shells out to `scripts/node/ops_helper.mjs` (406-409, 470-508), wraps `SupabaseDataProvider.save_timeline` with PAT (default) or service-role auth (394-398), `expected_version` from `load_timeline` (403), retries=3, `use_append_transport=False` (411-420). Writes remote via `update_timeline_config_versioned` RPC / append transport (timeline_io.py:150-293).

**3. Overlap with `reigh.reigh_data`** — `fetch_reigh_data` hits the same Edge Function with the same `project_id` (+optional shot/task/timeline) (run.py:33-69); response carries `timelines` with raw config + asset_registry (STAGE.md:62-71). So reigh_data **already does the lookup**; `projects list` is a thin projection. reigh_data does **no mutation** — the load→mutate→versioned-save loop lives only in data_provider/timeline_io, used by `projects edit` and the worker.

**4. `reigh.timeline_edit` gap** — `projects edit` covers only 3 ops (project.py:209-221). The local `timelines` CLI has the full surface: create/rename/finalize/tombstone/purge/set-default (timeline_parser.py:84-195), clip add/remove/move/retrack/retime/swap/replace/set-text/annotate (375-623), transition/effect/theme/track/audio/arrangement (625-1525). None of these exist remotely today.

**5. Callers** — `projects list`/`edit` appear in no docs/STAGE/scripts (repo-wide grep: only recovery strings project_handlers.py:449,454,466). Docs steer to `reigh.reigh_data` (SKILL.md:20,30,67; reigh_data/STAGE.md:32,48,57). test_cli_gate.py:103 pins `projects edit` as session-gated.

**6. Tests pinning routes** — test_project_cli.py:404,504,533,549,568,595,609,634; test_supabase_data_provider.py:56-354 (the reusable save core); tests/packs/reigh/test_reigh_data.py. Gating: `projects list/edit` are **not** in SPRINT1_UNBOUND_ALLOWLIST (gateway/__init__.py:149-172) — unlike `ls/create/select`, they require a session; local `timelines` edit verbs are `--project`-exempt (__init__.py:395-410).

## Suggestions
- **Keep in kernel**: `projects create/ls/select/default/theme/source/cost/export` (local store); `timelines` CLI (local surface).
- **Retire**: `projects list` (duplicate of reigh_data) and `projects edit` (node subprocess, 3 ops) — parser blocks + handlers.
- **reigh.timeline_edit spec**: `astrid timeline-edit --project-id --timeline-id --op <verb> [args]`, routed via `_dispatch_executor_main("reigh.timeline_edit")` (pattern: dispatch.py:346-347), reusing `SupabaseDataProvider` + `timeline_io.save_timeline` (expected_version, retries=3, force=False), ops implemented in Python via `astrid.core.timeline` edits, PAT default / `--service-role` escape, emitting event_descriptors; session-gated.
