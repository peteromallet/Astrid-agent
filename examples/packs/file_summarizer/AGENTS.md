# File Summarizer — Agent Guide

Use the v3 action surface to read text, validate a caller-authored summary,
and record a deterministic or caller-provided verdict. The caller should
review between actions; these actions do not keep a session open.

The four root `*.py` pipeline files and `golden/` event traces are historical
`astrid.core.orchestrate` examples outside the v3 catalog. Do not describe
them as current v3 entrypoints or claim lifecycle parity. The authored pack
guide is `docs/SKILL.md`.
